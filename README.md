# Commercial-friendly APIs

Public API lists tell you whether an API needs a key, HTTPS or CORS. They don't tell you whether you may put its data on a site with ads or affiliate links, store it, or show it on your own pages. This catalog does, with proof: every verdict links to the terms page and quotes the clause it rests on.

> ⚠️ **Not legal advice.** Terms change. Always re-read the linked terms before you ship.

**2051** APIs listed (716 more kept for reference as not applicable) · **1791** checked · 🟢 186 · 🟡 761 · 🔴 140 · ⚪ 964 · last check: 2026-11-26

## Legend

| | Meaning |
|---|---|
| 🟢 | Commercial use, storage and display are allowed (attribution may be required) |
| 🟡 | Allowed with real conditions: paid plan, self-hosting, limited caching, share-alike, or unclear terms |
| 🔴 | Not suitable for a commercial site |
| ⚪ | Not checked yet, or terms could not be confirmed |
| ⚠️ | The licence is the portal's default; individual datasets may carry other terms |

Scenario judged: a public website with ads and affiliate links that stores and republishes API data. Data licence and API terms are tracked separately because they often differ. Fields: `commercial_use`, `storage_caching`, `redistribution_display`, `attribution_required`, `share_alike`, each with evidence (URL, quote, date) in `data/apis/<id>.yaml`.
